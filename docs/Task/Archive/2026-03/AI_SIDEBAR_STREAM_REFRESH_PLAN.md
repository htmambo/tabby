# AI Sidebar 流式完成后未及时刷新修复计划

**状态**: ✅ 已完成 (完成时间: 2026-03-11)
**优先级**: P1
**负责人**: AI Assistant

## 任务目标

修复 AI Sidebar 在供应商请求已经完成后仍停留在 loading，必须通过滚动对话列表才显示最终结果的问题。

## 问题分析

当前侧边栏组件在流式消息完成、loading 状态切换、滚动按钮状态更新等路径上使用了延迟回调。若这些回调在 Angular 变更检测边界之外执行，组件状态虽然已经更新，但视图不会立刻刷新，直到下一次用户交互事件触发检测。

## 子任务

### 1. 排查异步回调与变更检测边界 ✅
- 检查 AI Sidebar 组件中的流式订阅、loading 状态切换和延迟刷新逻辑
- 确认最终完成事件可能在 Angular 上下文外更新组件状态

### 2. 收敛到稳定的刷新路径 ✅
- 在组件内部统一确保异步 UI 更新回到 Angular 上下文
- 保持现有滚动和流式输出行为，不改动消息协议和供应商请求逻辑

### 3. 验证与回归检查 ✅
- 运行静态错误检查
- 检查是否引入新的模板或类型错误
- 完成任务文档归档

- 已确保 loading 状态切换和延迟变更检测在 Angular 上下文内执行
