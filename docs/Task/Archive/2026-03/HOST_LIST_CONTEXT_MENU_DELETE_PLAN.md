# 左侧主机列表右键菜单补齐删除项计划

**状态**: ✅ 已完成 (完成时间: 2026-03-16)
**优先级**: P1
**负责人**: AI Assistant

---

## 任务目标和背景

用户反馈左侧边栏主机列表右键菜单缺少“删除”入口，导致必须进入设置页才能删除主机配置，操作路径较长。

## 现状分析

1. 右键菜单由 `tabby-core/src/components/appRoot.component.ts` 中的 `showRoyalConnectionContextMenu` 构建。
2. 当前菜单包含“连接 / SFTP / 重命名 / 复制 / 关闭全部连接”，未包含“删除”。
3. 设置页 `tabby-settings/src/components/profilesSettingsTab.component.ts` 已有删除确认逻辑，可复用同样的确认文案与交互。

## 子任务分解

### 任务 1：补齐右键菜单删除项 ✅
**状态**: ✅ 已完成

**具体改动**：
1. 在连接右键菜单中增加“Delete”菜单项。
2. 仅允许对可删除主机显示/启用删除（非内置，且有 profile.id）。
3. 删除前弹出确认框，确认文案与设置页一致。

**验收标准**：
- 右键菜单可见“Delete”项（对可删除主机）。
- 点击后出现确认弹窗。
- 确认后主机配置被删除并保存。

### 任务 2：行为一致性与回归检查 ✅
**状态**: ✅ 已完成

**实际改动**：
1. 删除前关闭该主机关联会话，避免悬挂引用。
2. 检查菜单其他功能（连接、重命名、复制、关闭连接）不受影响。
3. 对改动文件执行错误检查。

**验收标准**：
- 不出现新增类型/语法错误。
- 菜单既有功能行为保持一致。

## 实施结果

1. 已在 `showRoyalConnectionContextMenu` 中增加 `Delete` 菜单项（仅非内置 profile 显示）。
2. 已新增 `deleteRoyalConnection`，复用统一确认文案：`Delete "{name}"?`。
3. 已在删除流程中执行：关闭相关连接 -> 删除 profile -> 保存配置 -> 刷新侧边栏分组。
4. 已对相关文件执行错误检查，未发现新增错误。

## 风险评估与缓解

1. 风险：误删内置主机。
   - 缓解：删除入口仅对 `!profile.isBuiltin` 且 `profile.id` 生效。
2. 风险：删除后仍有会话绑定。
   - 缓解：删除前先关闭对应连接并清理绑定。

## 实施顺序

1. 修改菜单构建与删除处理逻辑。
2. 执行错误检查。
3. 更新任务状态并归档文档。
