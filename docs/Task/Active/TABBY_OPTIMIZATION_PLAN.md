# Tabby 项目全面优化计划

**状态**: 🔄 进行中 (开始时间: 2026-03-07)
**优先级**: P0 (紧急)
**负责人**: AI Assistant + 用户
**预计完成时间**: 12 周

---

## 📋 任务背景

基于对 Tabby 终端模拟器项目的深入分析（包括独立分析和 codex 架构审核），发现以下关键问题：

### 紧急问题
1. **Electron 38 支持即将结束**（2026-03-10，仅剩 3 天）
2. **插件系统依赖 Angular 私有 API**，阻塞框架升级
3. **ngcc 残留**，阻止 Angular 16+ 升级
4. **TypeScript 配置过于宽松**（noImplicitAny: false）
5. **大量依赖过期**（Angular 15 vs 21，落后 6 个大版本）

### 项目现状
- 代码量：约 70,809 行 TypeScript
- 插件模块：13 个
- node_modules：1.1GB
- 技术栈：Electron 38 + Angular 15.2.6 + TypeScript 4.9.5

## ✅ 现实检查（2026-03-15）

- Electron 已升级至 `^40.8.0`（已超过计划目标）
- Angular 已升级至 `^21.2.1`（已超过 16/17 目标）
- `ngcc` 脚本已移除，postinstall 不再调用
- `strictNullChecks` 已开启
- `noImplicitAny` 仍为 `false`（待处理）

---

## 🎯 任务目标

1. **消除紧急安全风险**（Electron EOL）
2. **解除架构级阻塞**（插件加载器重构）
3. **提升代码质量**（TypeScript 严格化）
4. **优化构建性能**（Webpack 缓存）
5. **升级技术栈**（Angular 16+）
6. **建立持续改进机制**（依赖管理自动化）
